Model Armor

A Google Cloud API that screens prompts and responses, for any model.

  • InjectionPrompt injection and jailbreak attempts
  • Sensitive dataPersonal and financial data, using SDP
  • Harmful contentHate, harassment, sexual and dangerous content
  • Malicious URLsPhishing and malware links in either direction
  • Any modelGemini or not, Google Cloud or not: it's one API call

Sensitive Data Protection

Google Cloud's service for finding and masking sensitive data. You may know it as Cloud DLP.

  • Finds it150+ built-in types: names, emails, phones, cards, national IDs
  • Masks itReplace with the type, redact, or tokenise so you can reverse it
  • At restScans Cloud Storage and BigQuery before anything reads them
  • In flightRuns inside Model Armor on every prompt and answer

Silent protection isn't protection. Log every verdict, and alert when the pattern looks like someone working through a list.

Cloud Logging

Where every Google Cloud service writes what it did, Model Armor included.

  • One placeYour app, Model Armor and Gemini calls, side by side
  • StructuredPrint one JSON line; it becomes a searchable entry
  • MetricsTurn a log line into a number: blocked prompts per minute
  • AlertsPage someone when that number jumps
  • QueryLog Analytics: ask your logs questions in SQL
