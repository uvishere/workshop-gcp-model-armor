What is Gemini Enterprise Agent Platform?

Google Cloud's platform for building AI apps and agents. You call an API; Google runs the model.

  • PrivateYour prompts and data never train public models
  • ManagedGoogle hosts, scales and updates it, with an SLA
  • One APIGemini and third-party models, same code

A Google Cloud API that screens prompts and responses, for any model.

Sensitive Data Protection

Google Cloud's service for finding and masking sensitive data. You may know it as Cloud DLP.

  • Finds it150+ built-in types: names, emails, phones, cards, tax file numbers
  • Masks itReplace with the type, redact, or tokenise so you can reverse it
  • At restScans Cloud Storage and BigQuery before anything reads them
  • In flightRuns inside Model Armor on every prompt and answer

Fix 3 · Access control and secrets

The bot can't leak what it never had. And the app gets the permissions it needs, nothing more.

IAM and Secret Manager

Who the app is, what it may touch, and where its keys live.

  • Own identityA service account per app, not the default compute account
  • Least privilegeOnly the roles it needs: Gemini, Model Armor, one bucket, one secret
  • Secret ManagerKeys stored once, versioned, rotated without a redeploy of code
  • Audit trailEvery read of a secret is logged: who, when, which version

How access control and secrets work

The key reaches the code at runtime. It never reaches the prompt.

Cloud Logging

Where every Google Cloud service writes what it did, Model Armor included.

  • One placeCloud Run, Model Armor, IAM and secret reads, side by side
  • MetricsTurn a log line into a number: blocked prompts per minute
  • AlertsPage someone when that number jumps
  • QueryLog Analytics: ask your logs questions in SQL

Ship it · Principle
Secure by default,
not by memory.
Its own identity, secrets mounted at runtime, no servers to patch. The safe way should be the easy way.

Cloud Run

Google Cloud's serverless platform. Give it your code, get an HTTPS URL.

  • One commandFrom source code to a live URL
  • Own identityEach service runs as its own service account
  • SecretsMounted from Secret Manager, never baked into the image
  • No serversGoogle patches the OS; it scales to zero when idle
