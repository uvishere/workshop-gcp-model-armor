The toolbox

The Google Cloud tools we'll use

  • Gemini EnterpriseAgent Platform: runs Gemini, the AI model that writes the answers
  • Cloud StorageHolds the bank's documents in a bucket
  • Secret ManagerKeeps passwords and API keys out of your code
  • SDPSensitive Data Protection: finds personal data and masks it
  • Model ArmorChecks prompts, documents and answers for attacks
  • Cloud RunRuns the app online, no servers to manage
  • Cloud LoggingRecords what happened, so you can spot attacks
The AI engine

What is Gemini Enterprise Agent Platform?

Google Cloud's managed home for Gemini. You call an API; Google runs the model.

  • ModelGemini 2.5 Flash: fast and cheap, right for a busy support bot
  • PrivateYour prompts and data never train public models
  • ManagedGoogle hosts, scales and updates it, with an SLA
  • One APIGemini and third-party models, same code

Cloud Run

Deploying to Cloud Run

Cloud Run runs your container at a public URL. No servers to manage, and it scales to zero when idle.

# deploy as its own identity, with its secret
gcloud run deploy securebank-bot \
  --source . \
  --service-account securebank-bot@… \
  --set-secrets ADMIN_API_KEY=…:latest
  1. 01A dedicated service account, least privilege
  2. 02Secrets mounted, never baked in
  3. 03Send an attack to the live URL
Look inapp/Dockerfile builds it; one gcloud run deploy ships it
Cloud Logging

Spotting attacks with Cloud Logging

Cloud Logging keeps every log in your project. Model Armor writes nothing there until you turn it on.

  1. 01Log which filter fired
  2. 02Alert on bursts from one caller
  3. 03Floor settings: a minimum for every team
